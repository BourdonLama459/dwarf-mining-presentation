# Dwarf Mining : notre cheminement

Présentation (HTML, un seul fichier) du projet Dwarf Mining, un jeu inspiré de
Dwarf Fortress construit pour apprendre à travailler avec Claude.

Ce dépôt ne contient **que la présentation**, aucun code du jeu.

- Navigation : flèches ← →, ou les boutons en bas ; un clic sur une image l'agrandit.
- Sur téléphone : de préférence en mode paysage.

## Versions

- `presentation-collegues.html` : version validée, figée, à présenter.
- `chronologie.html` : version de travail (même plan, peut évoluer).
- `index.html` : première version, organisée par thèmes.
